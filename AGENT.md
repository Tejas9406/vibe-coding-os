## What This Is

This is a **universal AI agent skill system** for vibe-coding. It contains everything an AI agent needs to plan, architect, build, review, deploy, and document any software project — from a simple CRUD app to a national-scale hackathon platform.

You are not a single AI. You are a **team**:
- A Project Orchestrator that classifies and routes your work
- A Universal Project Builder that enforces quality and lifecycle
- A Deep Research Team that investigates unfamiliar domains
- A System Design Engine for distributed architecture decisions
- A DevOps Decision Engine for CI/CD and deployment
- A Security Shield for AI-specific threats
- A Motion Wizard for premium UI animations
- Meta skills to build and improve the system itself

---

## 🚀 HOW TO START ANY PROJECT

**Step 1:** Give me any of these:
```
"Build me X"
"I want to create Y"
"Here is my problem statement: ..."
"Help me win SIH with this PS: ..."
"I need a Z for my startup"
```

**Step 2:** The Project Orchestrator classifies your project (SCOPE-S/M/L) and activates exactly the right skills.

**Step 3:** The agent works through the lifecycle — research, design, build, review, deploy, document — without you having to prompt every step.

## 📖 How to Use This in New Projects

### Option A — Reference from your centralized skills folder (Recommended)
Keep this repository at `D:/SKILLS` (or your preferred global folder), and in any project tell your AI agent:
```
Read D:/SKILLS/AGENT.md
Read D:/SKILLS/skills/00-core/project-orchestrator/SKILL.md
My problem statement is: [YOUR PS]
```

### Option B — Copy into project's `.agents/` folder
```bash
cp -r skills /path/to/your/new-project/.agents/skills/
cp AGENT.md /path/to/your/new-project/.agents/AGENT.md
```
Then tell your AI agent:
```
Read .agents/AGENT.md and .agents/skills/00-core/project-orchestrator/SKILL.md first.
My problem statement is: [YOUR PS]
```

### Option C — Global Skills Directory
Point your AI agent settings (e.g. Claude Code `~/.claude/settings.json` or Antigravity config) to this `skills` directory:
```json
{
  "skills_path": "D:/SKILLS/skills"
}
```
